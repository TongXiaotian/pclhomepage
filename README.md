你也可以下载Custom.xaml，来显示自定义的主页
下载Custom.xaml，打开pcl，点击设置，然后在点击个性化，下拉找到主页菜单，点击读取本地文件，点击生成教学文件，等会会弹出一款文件资源管理器，把里面的Custom.xaml替换成下载好的Custom.xaml，点击刷新主页就可以使用了
